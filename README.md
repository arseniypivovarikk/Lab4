# АгроМаркет (React)

Учебный проект: каталог фермерских продуктов на React + Vite. В архив включён Express API, чтобы приложение можно было запустить локально без отдельного репозитория сервера.

## Запуск

Нужен Node.js 20.19+ (или актуальная LTS-версия).

### 1. Запустить сервер API

```bash
cd agromarket-server
npm install
npm run dev
```

API будет доступен по адресу http://localhost:3000.

### 2. Запустить React-приложение

В другом терминале из корневой папки проекта:

```bash
npm install
npm run dev
```

Открыть http://localhost:5173.

## Функциональность

- Каталог фермерских продуктов, получаемый через `GET /api/products`.
- Поиск по названию товара.
- Добавление товаров в счётчик корзины.
- Адаптивная сетка CSS Grid и Flexbox.
- Блок доставки и семантические области `header`, `main`, `aside`, `footer`.
- Форма оптовой заявки с HTML-валидацией и отправкой на `POST /api/orders`.
- Серверная проверка имени, email и объёма заказа (минимум 10 кг).

## Лабораторная работа

Проект демонстрирует React-компоненты, `useState`, `useEffect`, получение данных через Fetch API, обработку состояний загрузки/ошибки, валидацию формы, CSS Grid, Flexbox и адаптивную вёрстку.
